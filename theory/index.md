## 这张图现在长到哪里了

经过八、九两个月的迭代，上面的六个问题组收敛成了一个更小的骨架。我现在用五个问题组织全部思考，它们比"话题"更根本，因为它们是按思考的顺序排的：

1. **世界如何运作**（原 01、02 组：存在、趋向、演化）
2. **人类是什么**（原 03 组：认知、能力、身体）
3. **我要什么，什么是好**（原 04 组：欲望、变化、好坏的定义）
4. **如何达到目的**（原 05 组：优化、杠杆、执行）
5. **在哪里落地**（原 06 组与组织、商业的实践）

分组还在，但它们现在挂在这五问上。读法也变了：过去是按兴趣跳读，现在是按问题分层读，先固定世界和人类的约束，再谈目的和方法。第 07 组的更新会持续挂在图尾，旧笔记被现实验证或推翻的痕迹，都会留在那里。

## 一些反复出现的词

| 词 | 在这里的用法 |
|------|------|
| **趋向性** | 我用来描述事物变化方向的一个概念，不把它当作普适定律 |
| **合理性** | 对"存在如何保持自洽"的一种提问方式 |
| **复杂性** | 观察生命、学习和组织如何积累结构的一个角度 |
| **具身组块** | 通过实践形成的能力痕迹 |
| **模态** | 大脑对对象和环境的可操作模型 |
| **世界线** | 用来思考选择与路径的一个比喻 |
| **概念事实** | 被临时当作事实使用的假设：承认它可能错，才敢用它，也才能更新它 |
| **目的** | 趋向加上人类限制之后的样子；人生是达到目的的过程 |
| **基准状态** | 好状态的公共地基：休息和工作效率都建立在它上面 |

## 这张图会继续变

这些文章来自不同阶段，成熟度也不一样。后续更新会优先保留问题、证据和修正过程，而不是把旧想法包装成结论。能留下来的，应该是更清楚的问题和更可靠的行动；不能留下来的，就让它自然退场。
