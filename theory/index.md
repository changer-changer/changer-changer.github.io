> **Thinking in progress**
>
> 这里不是一套已经完成的哲学体系，也不是对世界的最终解释。它更像一张持续修改的地图：我把经验、阅读和实践中的问题放在一起，观察它们之间可能存在的联系，也允许它们被新的证据推翻。

## 这张图怎么读

下面的文章按照问题分成六组。分组只是为了方便回看，不代表它们已经形成严密的学派或完整的理论。每一篇都可以单独阅读，也可以把它当作一段仍在接受现实检验的工作笔记。

## 一些反复出现的词

| 词 | 在这里的用法 |
|------|------|
| **趋向性** | 我用来描述事物变化方向的一个概念，不把它当作普适定律 |
| **合理性** | 对“存在如何保持自洽”的一种提问方式 |
| **复杂性** | 观察生命、学习和组织如何积累结构的一个角度 |
| **具身组块** | 通过实践形成的能力痕迹 |
| **模态** | 大脑对对象和环境的可操作模型 |
| **世界线** | 用来思考选择与路径的一个比喻 |

## 这张图会继续变

这些文章来自不同阶段，成熟度也不一样。后续更新会优先保留问题、证据和修正过程，而不是把旧想法包装成结论。能留下来的，应该是更清楚的问题和更可靠的行动；不能留下来的，就让它自然退场。
